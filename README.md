This repository showcases a **real-world Accessibility Testing project** performed on the **Spartoo E-Commerce Website** using industry-standard accessibility testing practices and **WCAG 2.1 / WCAG 2.2 Level AA Guidelines**.

The project demonstrates the complete accessibility testing lifecycle including:

- ✅ Accessibility Test Planning
- ✅ WCAG Compliance Validation
- ✅ Manual Accessibility Testing
- ✅ Automated Accessibility Scanning
- ✅ Keyboard Navigation Testing
- ✅ Screen Reader Validation
- ✅ Requirements Traceability Matrix (RTM)
- ✅ Accessibility Defect Reporting
- ✅ Test Case Design
- ✅ Comprehensive Documentation

This portfolio demonstrates practical accessibility testing skills expected from **QA Engineers, Accessibility Testers, SDETs, QA Leads, and Quality Engineering Teams.**
